Masking Implementation Details

Static Data Masking permanently transforms sensitive data in development or test environments:

  • Email addresses: First 2 characters preserved, rest masked (e.g., jo**@example.com)
  • Contact numbers: Last 4 digits preserved, rest masked (e.g., *******1234)
  • Passwords: Completely replaced with hash values
  • Additional info: Replaced with generic text

Static masking is implemented via the functions fn_MaskEmail() and fn_MaskContact().

Dynamic Data Masking transforms data at query time based on the user's role:

  • AdminRole: Full access to most data (except passwords)
  • FacultyRole: Can see student names but contact/email is masked
  • StudentRole: Can only see their own data; no access to other students

Dynamic masking is implemented via database views: AdminStudentsMaskedView, FacultyStudentsMaskedView, and StudentSelfMaskedView.
